# Support

Munarium Lens is available under [Apache-2.0](LICENSE). The repository
currently provides a development scaffold and design. Supported accelerator
profiles and operating limits will be listed with the qualifying release.

Use GitHub Issues for public questions and reproducible defects. Include the
source revision, OS, toolchain and minimal sanitized probe. Use the private
route in [Security](SECURITY.md) for vulnerabilities. Open-source availability
carries no commercial support commitment. Contact **info@ioka.io** for
commercial enquiries.
