# Agent guidance for Munarium Lens

This public Apache-2.0 repository owns the optional Lens inference endpoint.
Read [CONTRIBUTING.md](CONTRIBUTING.md), [SECURITY.md](SECURITY.md) and the
[design plan](docs/design-plan.md) before editing. Keep this file and
`CLAUDE.md` identical.

- Confirm the repository, branch, remote and working-tree status. Preserve
  unrelated edits. Keep changes focused, run the documented checks and report
  unavailable evidence as such.
- Keep credentials, weights, local mounts, private corpora, request text,
  judgments and restricted receipts out of tracked files, logs and PRs.
  Use synthetic test inputs. Do not force-add an ignored file.
- Preserve approved profile identity, offline artifact verification,
  authenticated service transport and content-free errors. Server owns
  authorization, placement policy, metering, enrollment and citation release.
  Follow the hub decision and export workflow for shared wire changes.
- Preserve protected-file ownership and repository checks. Use PRs against
  `main`. When authorized to commit, use the configured contributor identity
  and `git commit -s`. Keep AI provenance factual in the PR's disclosure
  field. Leave human review and rights attestations to the contributor.
- Publishing, merging, rolling out and paid qualification require explicit
  authorization. Suspected vulnerabilities use the private reporting
  process in [SECURITY.md](SECURITY.md).
